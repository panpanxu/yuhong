# 《于洪》悬疑推理全解析

中篇小说《于洪》是班宇写的关于东北2000年前后大下岗背景下的故事。《余红旧事》从这篇小说改编而来，我认为不如小说精彩精炼。**在阅读这篇文章之前，我建议你还是先读一遍原版的小说。因为接下来，我将对这篇小说做全面的悬疑推理解读**。

如果你读过阿加莎的悬疑系列小说，那么，《于洪》的叙事风格就不会陌生，这篇小说基本上仿照了《罗杰疑案》的叙事结构来展开。

《罗杰疑案》和《于洪》的叙事都由凶手视角展开，阅读故事过程中，凶手第一人称视角对故事的叙述，你可以直接把小说当成是凶手对警察的一次完整口供，这一点在《罗杰疑案》上非常典型。

不过《于洪》小说内容中，包含了大量的凶手第一视角的内心独白，阐述了对亲人的种种情感。这些隐秘的情感显然不能被看作审讯口供，这些是班宇的作者的个人化小说风格，这篇小说不仅仅是单纯的一次杀人抢劫案件，更重要的，是他对东北过去体制化时代的怀念和体悟。

小说整体结构，由主角刘阳讲述一段或真或假的5年时间的故事，在最后的一小段，由郝鹏飞揭露一段或真或假的真相，完成反转。

## 刘阳的叙述故事脉络为：

**退伍 → 在家待业 → 跟着郝鹏飞卖烟 → 发现郝鹏飞行踪奇怪 → 沈阳杀人抢劫案告破（案犯李德武被抓） → 和郝洁恋爱结婚 → 卖烟被抓 → 警察上门询问郝鹏飞去向 → 去汽修公司上班 → 发现郝洁不孕 → 遇到物流公司女老板陈红 → 和陈红发生情感/工作关系 → 陈红怀孕 → 与郝洁离婚 → 陈红生子 → 发现陈红前夫是李德武 → 陈红公司被警方封账 → 事发 → 郝鹏飞找到刘阳 → 郝鹏飞戳穿刘阳的伪装**

## 郝鹏飞的叙述故事脉络为：

**退伍 → 在九路市场看自行车工作 → 跟着刘阳卖烟 → 沈阳杀人抢劫案告破（案犯李德武被抓） → 听到风声被通缉 → 逃亡 → 找到姐姐郝洁（告诉她刘阳可能牵扯杀人案，但姐姐不信） → 跟踪刘阳和陈红 → 找到陈红 → 在洗浴中心找到刘阳 → 在医院外找到刘阳 → 戳穿刘阳伪装**

## 小说关键内容的注释

根据上述故事脉络，下面是对小说关键情节叙述的注释。故事本身是个罗生门，这里我将彻底讲清楚小说的悬疑铺陈。（JioNLP）



- 一九九九年，我从部队复员，在家等分配，大半年过去，一点儿动静都没有，我心里有点急，去安置办问过几次，说是目前就业形势不好，这一批没单位接收，只能耐心等待，要相信政府，祖国是没有忘记你们的。（**整篇小说，犯罪动机就是，政府和祖国把他们忘记了。这一点类似于电影芳华中，男主角刘峰残废后蹬三轮做生意被城管打**）

- 我有时候做梦，还总能梦见当时的场景，半夜里，站在桥上，江水涌动，高出防洪堤数米，天空被雨浸洗，星星全被覆盖，我们相互搀着走，由下至上，沿江而行，暴雨不停，很难看清前路，至水深处，黄泥漫过来，几近胸口，简直快要窒息。（**立于洪水之中，点名小说名字《于洪》**）

- 我妈说，郝鹏飞（三眼儿）在九路市场楼下看自行车呢，叼着烟卷儿，腰里别个包儿，见我可亲了，也没收费，站那唠了半天。（**郝鹏飞实际上对刘阳非常好，很亲近刘阳，因此也亲近刘阳母亲。**）

- 我主要是不爱联系三眼儿，对这个人印象一般，虽都是沈阳的兵，但他做的很多事情我都看不太惯。刚入伍时，我俩关系本来不错，一个地方上来的，比较近，能唠到一起，有个照应，后来发现他品行有问题，屡教不改，还因为这个被处分过，我就有点瞧不上。也是奇怪，三眼儿的手不老实，却从来不拿沈阳人的东西，专门欺负那些别的地方来的，对我们还很大方，经常买烟，四处散，办事说到做到，所以也不明白他到底咋想的。（**此处刘阳编造了关于郝鹏飞的人品，扭曲了部分事实，可以理解为向警察告知的口供，引导警察怀疑郝鹏飞。而事实上，郝鹏飞的确对刘阳之所以很好，是因为抗洪时，刘阳拉了郝鹏飞一把，对于郝鹏飞是过命的交情。**）

- 我说，还在九路市场看车吗？对面说，换地方了，铁西商业大厦，那边车多。（**在沈阳入室抢劫杀人案发之前，郝鹏飞已经不在九路市场看车。**）

- 我观察了一会儿，乐出声来，三眼儿回头一看，发现是我，惊呼一声，我操，你咋来了呢。我说，来找你喝酒，战友聚会。三眼儿说，回来这么长时间，一次没见到，老想你了，有一次看见你妈了。（**从刘阳视角，再次印证郝鹏飞对刘阳非常有好感。**）

- 我说，可不咋地，青春献党，纯属白忙。（**这句话透露出刘阳对jun对和政府的失望，也为后续犯案留下伏笔**）三眼儿说，那也不能这么讲，不知道你，反正我还是有收获。（**首先，这句话表明相比刘阳存在犯罪动机，郝鹏飞并没有对政府的怨恨，因此也就没有作案动机。此外，三眼当过侦察兵，他指的收获应该是对市场人流的观察，看车从某种程度上，算是部队学习到的能力在地方上的运用**）

- 我说，我也有，不后悔，就是社会变化太快，有点跟不上节奏，你几点下班，晚上好好唠一唠。三眼儿说，现在就走，妈了个逼，今天不收费了，千禧年大酬宾，随便停去吧。（**郝鹏飞的性格是大大咧咧，不在乎钱的，更在乎兄弟战友情。**）

- 三眼儿悄悄给我主意，先是宽慰一番，说最近联络上一个以前部队里的领导，转业数年，颇有能力，回头见个面，实在不行送点礼，求他帮帮忙；然后又说，其实靠别人不如靠自己，他家离着于洪广场很近，那边刚开发出来，住户渐多，夏天时摆了不少烧烤摊位，还有打扑克的，乌乌泱泱一大片，冬天冷，人少一些，但也有，穿着棉袄烤炉子喝大酒，一整半宿，就这么大瘾。我说，烧烤我不会啊，没干过，扑克更不行了。三眼儿说，不让你烤，我琢磨着，咱俩出个烟摊儿，不管喝酒还是打牌，都挺费烟，一宿得好几盒，咱俩去卖烟，肯定能行，到时换着来，一替一天，晚上过去，啥也不耽误，还不累，捡钱似的。我说，也没卖过烟啊，去哪儿上货都不知道。三眼儿说，我有路子，保真，还便宜，你出人就行，以后也不耽误你白天上班，能长远，就是冬天在室外杵着，那是真冷。（**上述对话双方，角色完全被互换了。第一 ，此时郝鹏飞有工作，刘阳没工作，因此，“不耽误你白天上班”，其实是刘阳对郝鹏飞说，晚上卖烟，不耽误郝鹏飞白天看车。另外，郝鹏飞建议刘阳联系部队领导是真，这里的领导是李德武；刘阳给出的建议是不求人，“靠别人不如靠自己”以及摆摊卖烟。所以两条建议是两个人分别给出的，而非都是郝鹏飞给出。**）

- 进货的钱，我俩各出一半，我多个心眼，每个品种的进价都让他写下来，散盒多少钱，成条又是多少，全列清楚，三眼儿不太在乎这些，大大咧咧，但我得算计，上货的钱是管我妈借的，不敢马虎。（**和此前郝鹏飞大大咧咧性格做对比，刘阳性格谨慎，对钱计较，心眼颇多。**）

- 过了一段时间，我发现他（郝鹏飞）卖得（烟）还不如我呢，但我也坚持照半分钱，毕竟是人家张罗的买卖。（**依照刘阳的性格，以及我们对事实的分析，这里刘阳扭曲了事实，郝鹏飞卖烟并不差，之所以这么说，是为了引导警察怀疑郝鹏飞。**）

- 我说，等三眼儿赚钱了，让他给安个有线电视，能看好几十个台，天天放香港电影。郝洁说，指着他呢，一天到晚不着家。（**再次用郝洁之口，引导警察对郝鹏飞的怀疑。**）

- （在郝鹏飞家待的日子久了）一来二去，我发现郝洁平时不看电视，只有我去了，那台电视机才点开，专项服务，规格挺高。（**郝洁喜欢刘阳**）

- 到医院后，一顿抢救，各种仪器全配上，郝洁一点主意都没有，神情恍惚，感觉随时会昏过去，道儿都走不直。凌晨时，状况稳定一些，我去厕所洗了把脸，抽棵烟，回到病房，怎么想怎么不对，就问郝洁，三眼儿哪儿去了呢。郝洁说，指着他呢，联系不上。我说，那不能啊，他天天下了班不就去广场卖烟么。郝洁说，不知道，最近烟也没去卖，成宿不回家，没敢跟你说。（**郝鹏飞干嘛去了？根据前面分析，郝鹏飞要是不卖烟，刘阳的性格，对钱和账的清楚程度，不可能发现不了。因此，这里是刘阳的撒谎。**）

- 我陪郝洁在医院熬了一宿。第二天早上，三眼儿赶了过来，还是听邻居说的，灰头土脸，头发根根立着，衣服邋遢，跑进病房，腰包里的零钱叮当乱响。郝洁瞪着他，也不说话，没好脸色，我问他昨晚去了哪里，他没搭理，蹲在他妈床前，一副要哭还哭不出来的熊样。郝洁说，少整景儿，这时候来劲儿了。三眼儿也没吭声。（**郝鹏飞应该是白天看车，晚上卖烟，此时才知道母亲急救赶到医院，但姐姐埋怨他。**）

- 我挺来气，你自己的妈，你不照顾，买卖也不做，一天到晚，到底想干啥呢，但这些话，这个场合我又不好讲出来。（**刘阳虚构**）

- 我刚起身，郝洁忽然一把将我抱住，贴在背上，低头亲我的脖子，我有些激动，加上之前对她也有好感，便转过头去，踮脚吻她，气喘吁吁，胡乱扯着衣服，她个子高，身上比我想象得还要软，并且发烫，像一株热带植物，不断生长，盘绕着我，具体感觉说不上来，反正就是不愿意分开，只想缠在一起。我把她拉去沙发，她摇了摇头，攥紧我的手，将我带向里屋。（**其实这里，我认为，涉及到情感的部分，刘阳并没有撒谎，两人相互有好感，至于谁是主动的，并不重要**）

- 郝洁哭得上不来气，我也不好受，想到刚出院的时候，有那么几天，脑子清醒一些，老人嘴里蹦出几个零碎的词儿，我听了个大概，意思是说，想去医院，别有那么一天走在家里，不好，遭人厌。就这么一个愿望，最后也没实现。人有时候就是这样。（**感觉故事里的很多人，都是这样的结局。**）

- 老人走后，郝洁跟三眼儿的关系也处不好，总不对付，鸡毛蒜皮的小事儿，老是吵架，我劝也没用，三眼儿觉得我向着他姐，久而久之，跟我也有点隔阂，后来这些事情我就不怎么参与了。（**郝洁为何与郝鹏飞吵架？并不仅仅是因为弟弟在照固母亲方面不尽心，同时也暗含了，郝鹏飞与刘阳关系的隔阂，隔阂的原因，应该是郝鹏飞察觉到了刘阳行动的异象，而姐姐郝洁向着刘阳，而非刘阳说的“我向着他姐”。**）

- 郝洁跟我说，以前她弟去当兵，妈生了病，指望不上别人，亲友借遍，也不够治疗的钱，放任不顾的话，肯定说不过去，眼看着情况一天天恶化，她便跟一个朋友去了大连，在那边待过一段时间，虽不得已，但也不是借口，这事儿总掖在心里，迈不过去。（**郝洁坦白过往不堪历史，希望朝前面对。**）

- 那阵子，基本上只有三眼儿自己在卖烟，也是有一搭没一搭，进的货不见下，怎么带去的又怎么带回来，还有几天，他一个人空着手出去的，后半夜才回来。（**印证前面编造的郝洁的话，郝鹏飞有没有卖烟，刘阳最清楚，而非郝洁最先知道。并且应该是刘阳没怎么卖烟，郝鹏飞发现并告知郝洁。**）

- 四月底，沈阳破了个大案，全城轰动，新闻滚动播出，群众拍手称快，电视台还拍了个纪录片，全程记录审讯过程，每天一集，看着很受触动，人性的险恶与残暴，一览无遗，比电视剧都有意思。官方称之为四一〇大案，持械抢劫杀人，手段残忍，情节恶劣，烧过信用社，劫过运钞车，手上十几条人命，主犯共四人，两对兄弟，主事儿的哥俩姓李，哥哥李德文，在线路大修段上过班，脑子好，行事缜密，性格不驯服，对纪律之类天生反感，案子都是他来谋划，弟弟李德武，以前当过兵，身法不错，也敢下狠手，最后一次败露时，李德文因买枪未遂在广州服刑，没有参与，其余三人筹划不周全，抢劫一位九路市场的业主时留下痕迹，这才一举告破，进而牵出之前的连环案件。（**于洪广场抢劫杀人案发**）

- 后来有一天，我想起来，这人以前常在扑克摊上打牌，我见过好几次，梗着脖子，有几分派头，讲话也怪。之所以有这么个印象，是他有次喝得比较醉，走过来问我，有没有裸体打火机？我说，打火机有，五毛钱一个。他说，要裸体的，有画面儿的那种。我说，那没有。之后他转身离开，嘴里嘟囔不停，我心说，点个火而已，怎么这么多要求。（**刘阳向警察的口供，见过被害者，且从买打火机看出，刘阳知道被害者有钱**）

- 我回来讲给郝洁，她叹了口气，说道，不管怎么说，这家也太惨了，孩子那么小，这伙人都该毙。我说，是，那肯定没跑儿。（**刘阳向郝洁隐瞒杀人案。**）

郝洁说，但世界是广阔的，有大海，有渡船和帆，有闪烁的光，万物是凝聚，而人在其中，我给你念念结尾。

## 以下是郝鹏飞的供述

```

他摘去口罩，嘴角上扬，看着我笑。

我对着夜空说，好久不见。

他说，五年零三个月。

我说，我是做梦呢吧，三眼儿啊。

三眼儿说，说不好，这些年啊，谁过得都像一场梦。

我说，三眼儿，有两下子，能找过来。

三眼儿说，没想找，也是赶巧，我来办个手续。

我说，给谁办。
```

## 后评

乱世出好故事，就像三国演义，90年代到2000年初的东北，也是这样。

通过教育和体制，把人驯化成一个个机器上的螺丝钉。然后突然有一天，再告诉你，不需要这颗螺丝钉了，请离开。退伍军人如此，东北国企的工人也是如此。其实可以从故事里看出来，退伍军人安顿不好，社会很容易出现大的乱子。2000年前后如此，现在2026年，依然如此。

故事里，除了退伍军人找不上工作，还包括国企工人下岗，郝洁这样的年轻女性，出卖肉体换钱，但是这些人没有什么反抗能力，只能被动选择接受。

整个不长的中篇里，出现了大批的下岗人员，刘阳、郝鹏飞、郝洁、刘阳的母亲，都是在社会洪流下的牺牲品。李德武和陈红，则代表了另外一类人，胆子大、心黑，靠着不择手段和我行我素，享受了富裕的生活。

刘阳面对政府的不给安置工作，他的认知是“青春献党，纯属白忙”，而郝鹏飞则是“那也不能这么讲，不知道你，反正我还是有收获。”两个人对体制的不同态度，决定了他们此后的人生轨迹。

刘阳是在被牺牲的人群里面，那些十分清醒，且同样具有不择手段和我行我素的人蜕变的过程，刘阳蜕变了，所以他拿到了大量的钱。而郝鹏飞依然相信体制的教化，保持了善良。

郝鹏飞在姐姐的梦中说对不起姐姐。他和姐姐的悲剧从何而来？是不该向刘阳推荐从前的部队领导李德武？是不该跟着刘阳去卖烟？还是不该支持姐姐和刘阳的婚姻？可是刘阳是在洪水中拉了郝鹏飞一把的人。所以郝鹏飞的矛盾也来源于此。可是归根结底，郝鹏飞没有做错任何事情，而最终的结局，是一个善良的人，背了杀人的黑锅，而最终似乎只能走向真正的杀人。

故事给了这些人将死的结局，李德武明确死了，而陈红则即将失去金钱，刘阳则在开放式的结尾里，隐晦的走向死亡。可是，故事如果对刘阳做出死亡的惩罚，郝鹏飞就献祭了自己。如果郝鹏飞继续隐忍苟活，刘阳似乎不会得到惩罚。故事的矛盾点就在于此。

**归根结底，到底是谁害了郝鹏飞？**

在混乱的社会里，没有规则的社会里，应该不会这样的，胆子大，心黑，脸皮厚，依然可以吃到红利，而遵守规则，听从教育和规训，安分地做一个个螺丝钉，最终的结局，依然是被磨损，被抛弃。只要这样的事情还在发生，就还会有新的人立于洪水之中。
