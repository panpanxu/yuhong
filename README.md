# 于洪 · 互动小说

依据班宇短篇《于洪》与其悬疑推理全解析改编的网页互动小说。单文件离线可玩，也可以选择配置大模型，在关键节点续写剧情。

## 在线玩

发布后可直接访问：`https://panpanxu.github.io/yuhong/`

## 怎么玩

- 打开后点「随机进入一个人的叙述」，系统从四个人里随机抽一个；也可以手动选：
  - **刘阳** — 退伍兵，于洪广场摆烟摊
  - **郝鹏飞** — 外号三眼儿，侦察兵出身
  - **郝洁** — 三眼儿的姐姐，从大连回来
  - **陈红** — 物流公司女老板，李德武的前妻
- 剧情贴着原文走，你在关键节点上的选择会改变故事走向，并影响结局。
- 右侧面板显示人物状态：和几个人的关系、手里的钱、警方的注意。
- 点击文字可以跳过打字；顶部能保存/读取进度。

## 模型设置（可选）

首页「模型设置」可以填 OpenAI 兼容接口的地址、模型 ID 和 API Key。配好后，每章末尾会由模型续写一小段；不填也能完整游玩，只是剧情按写好的走。

注意：网页直接调用外部接口可能受浏览器跨域（CORS）限制，需要模型服务端开启 CORS。

## 本地开发

剧情与引擎源码在 `game/`，构建脚本会把它们合成单文件：

```bash
node game/build.js
```

产物写到根目录的 `于洪.html`，`docs/index.html` 用于发布。

## 目录

- `game/` — 引擎、剧本、样式、构建脚本
- `raw/` — 原小说与解析文本（用于核对人物与情节）
- `docs/index.html` — 发布用的单文件网页
- `于洪.html` — 构建产物
